# C09 「凌霜」银红女将战甲
## 基础信息
- 编号：C09
- 官方定名：凌霜
- 别名：女将军战甲、仙侠女武将服、银红战裙
- 风格定位：英气飒爽、女将军、仙侠武将、巾帼英雄、战斗风
- 适用场景：古风人像拍摄、仙侠剧女武将/女将军造型、汉服商拍、cosplay
## 服装结构（全套）
### 1. 金属甲胄
- 胸甲：亮银色哑光金属胸甲，版型贴合身形，表面雕刻金色缠枝暗纹，胸口金色雕花+红宝石装饰
- 肩甲：多层银色金属肩甲，边缘雕刻金色花纹，造型硬朗
- 臂甲：银色金属护臂+护腕，同样带金色雕刻细节，红色绑带固定
- 腿甲：银色金属护腿+战靴，带金色雕花，版型贴合腿型
### 2. 内层战裙
- 版型：齐腰大摆长裙，拖地长度，自然垂坠
- 面料：银白幻彩闪粉雪纺，带银色+淡紫色暗纹刺绣，有珍珠光泽感，垂坠飘逸
### 3. 披风
- 版型：无帽长披风，从肩部垂下，拖地长度，垂坠飘逸
- 面料：酒红色半透雪纺，带金色细闪碎花暗纹，通透轻盈
- 装饰：领口银色雕花搭扣+红宝石装饰，固定在肩甲上
### 4. 装饰细节
- 腰间：多层红色绑带固定，搭配金色镂空雕花腰饰，两侧垂落酒红色飘带，飘带底部绣金色缠枝花纹
- 领口：红色宝石吊坠项链
