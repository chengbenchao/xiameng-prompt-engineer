# C12「红狐」红色狐妖纱裙

## 基础信息
- **关键词**: 红色 / 狐妖 / 纱裙 / 妖娆 / 魅惑
- **适用场景**: S2 夜景冷调, S5 反派老巢, S18 紫蓝巨环仙域

## 服装结构（全套）

### 1. 主裙
- **版型**: 修身鱼尾裙，下摆开叉至大腿中部
- **色彩**: 正红色渐变至暗红，裙摆带黑色暗纹
- **面料**: 外层红色透明薄纱，内层暗红色丝绸衬裙

### 2. 外披
- **款式**: 半透红色纱质披风，边缘绣黑色狐纹
- **长度**: 拖地，走动时飘动如狐尾

### 3. 配饰
- **腰部**: 黑色编织腰带，悬挂红色狐形玉佩
- **头部**: 红色狐耳发饰，两侧垂落红色流苏
- **手部**: 红色半透纱质长手套，至手肘

## 面料细节
- **外层**: 红色透明薄纱，轻盈飘逸，边缘黑色刺绣狐纹
- **内层**: 暗红色丝绸，光泽柔和，贴身修身
- **披风**: 半透红纱，黑色狐纹刺绣，拖地设计

## 色彩
- **主色调**: 正红色渐变至暗红
- **辅色**: 黑色狐纹刺绣、红色流苏
- **点缀**: 红色狐形玉佩、狐耳发饰

## 完整服装描述段落（可直接复制入主体第 7 维）
```
她身着一袭红色狐妖纱裙，修身鱼尾版型，下摆开叉至大腿中部，外层红色透明薄纱渐变至暗红，裙摆绣黑色狐纹暗花。内层暗红色丝绸衬裙贴身修身，光泽柔和。外披半透红色纱质披风，边缘黑色狐纹刺绣，拖地设计如狐尾飘动。腰间系黑色编织腰带，悬挂红色狐形玉佩，头戴红色狐耳发饰，两侧垂落红色流苏，红色半透纱质长手套至手肘。
```
