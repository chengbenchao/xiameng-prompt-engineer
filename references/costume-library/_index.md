## 📝 使用规则

1. **用户指定服装编号**（如"用 C03"）→ 直接跳转到对应文件查找
2. **用户描述风格**（如"要一套商务西装"）→ 通过上表定位品类 → 在品类文件中查找最匹配条目
3. **未匹配到已知条目** → 按用户描述新建条目，追加到对应品类文件末尾，编号递增
4. **跨品类混合**（如"古装+现代混搭"）→ 分别提取两个条目中的元素组合
