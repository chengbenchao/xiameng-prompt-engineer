# 👕 现代装服装库 (Modern Costume Library)

**用途**：在主体第7维描述中引用服装细节，避免每次都重新编造。
**用法**：用户指定服装关键词 → 查表匹配 → 直接复制服装描述段落到提示词中。
**版本**：v1.0（2026-04-27）
