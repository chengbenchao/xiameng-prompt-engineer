# 🎥 运动镜头提示词库 v1.0 (Motion Camera Prompt Library)

**用途**：用于 AI 视频生成（Runway/Pika/Kling/Sora 等），区别于静态图提示词。
**版本**：v1.0（2026-04-29）

---

## 📐 核心结构模板

运动镜头提示词 = **12 个模块**，按顺序组合：

```
1. 场景定调
2. 镜头运动描述
3. 前景层（动态细节）
4. 中景层（主体+缓慢运动）
5. 背景层（建筑/环境+光效）
6. 天空/远景（巨型元素+漂浮运动）
7. 光效结构（多层光源）
8. 色温（多光源冷暖对比）
9. 【运动控制】
10. 【镜头控制】
11. 【空间层级】
12. 【负面提示词】
```

## 📝 使用规则

1. **运动镜头提示词 ≠ 静态图提示词**：必须包含镜头运动、速度、稳定度、动态元素描述
2. **节奏一致**：所有元素的运动速度必须统一（极慢/慢/中/快），不可出现"极慢推镜+快速飞舞"的矛盾
3. **空间三层**：前景-中景-背景必须清晰，每层至少一个动态元素
4. **负面提示词必须包含运动相关排除项**：如"快速运动、镜头抖动、不真实运动"等
5. **镜头控制独立成段**：用【镜头控制】【运动控制】【空间层级】三个标签分段，便于AI理解

## 🔄 与静态图提示词的区别

| 维度 | 静态图提示词 | 运动镜头提示词 |
|------|------------|--------------|
| 镜头 | 焦段+光圈+光位 | 运动类型+速度+稳定度 |
| 主体 | 姿态+表情 | 运动方式+速度+惯性 |
| 环境 | 背景+前景 | 三层动态元素（前景/中景/背景各自动态） |
| 氛围 | 情绪关键词 | 运动节奏+呼吸感 |
| 负面提示 | 低画质/变形 | + 快速运动/镜头抖动/不真实运动 |
| 额外模块 | 无 | 【运动控制】【镜头控制】【空间层级】 |
