## 📎 飞书文件附件限制

**⚠️ 关键坑点**：用户通过飞书聊天窗口上传的文件（如 zip 压缩包）**不会自动下载到服务器磁盘**。文件存储在飞书云端，本地文件系统无法访问。

| 场景 | 结果 |
|------|------|
| 用户飞书聊天发 zip | 文件在飞书云端，磁盘找不到 |
| 用户飞书聊天发图片 | 可能缓存在 `/root/.openclaw/media/inbound/` |
| raw.githubusercontent.com | ✅ 单文件可下载 |
| GitHub API | ✅ 元数据可访问 |

**替代方案**：需要用户提供文件时，让用户：
1. 发本地文件路径（如已在服务器上）
2. 传到可公网访问的 URL
3. 或通过其他渠道（邮件、网盘链接）分享

**用户预期**：用户期望飞书上传的文件能被直接访问。当多次找不到时会产生困惑——应第一时间告知此限制，避免反复搜索。
