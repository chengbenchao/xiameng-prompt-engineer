# 雪林孤侠独行

> 标签：国风武侠/孤侠独行/秋冬雪林 | 画幅：--ar 16:9 | 推荐模型：国风+港风复古模型
```
独家秘法生成东方武侠秋冬雪林独行场景，主体是身着玄色暗纹宽大厚披风、头戴宽檐黑斗笠的古风侠客立于雪后林中，背景是密集的浅棕黄色光秃落叶林，地面堆积白皑皑残雪，整体暖黄复古胶片色调，充满苍凉孤寂的江湖独行客氛围感。
35mm人文镜头，f/2.8光圈，侧顺光，暖黄复古自然光线，光比1.5:1柔和层次。环境色温4000K暖黄复古调，情绪关键词：孤侠独行、苍凉孤寂、复古江湖、老电影氛围感。电影感画面，超写实质感，8k超高清，RAW原图，复古港风武侠电影胶片质感，颗粒感适中，色彩浓郁自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非古风武侠场景，现代/日式元素乱入，斗篷/斗笠造型错误。
```
