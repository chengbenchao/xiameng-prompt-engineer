# 风雪骑驴赶路

> 标签：国风武侠/风雪赶路/江湖行旅 | 画幅：--ar 16:9 | 推荐模型：国风+复古电影模型
```
独家秘法生成东方武侠风雪行旅场景，主体是玄色斗篷斗笠侠客骑黑驴走在积雪山路，旁侧两名布衣书童随行，一人前头挑着朱红和赭色行李担子，一人牵驴引路，背景是雾气朦胧的米黄色雪山和光秃桦树，整体暖黄复古胶片色调，充满苍凉悠远的江湖行路氛围感。
35mm人文镜头，f/4光圈，侧顺光，暖黄复古雾天自然光线，光比1.5:1柔和层次。环境色温3800K暖黄复古调，情绪关键词：风雪赶路、江湖行旅、悠远苍凉、老电影氛围感。电影感画面，超写实质感，8k超高清，RAW原图，复古港风武侠电影胶片质感，颗粒感适中，色彩浓郁自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非古风武侠场景，现代/日式元素乱入，人物/驴/担子造型错误。
```
