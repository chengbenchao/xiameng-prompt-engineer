# 紫花峡谷仙境

> 标签：国风仙侠/奇幻秘境/世外花谷 | 画幅：--ar 16:9 | 推荐模型：国风模型
```
独家秘法生成东方仙侠紫花峡谷仙境场景，主体是身着素白长袍的仙人立于峡谷崖边深褐色巨石上，俯瞰绿松石色澄澈河流，两岸漫山遍野是紫绒色球状繁花夹杂少量丹红色花朵，背景是青灰色陡峭巨型山壁，山间飘荡着大团蓬松的白色云雾，整体空灵梦幻，充满世外仙境的超然氛围感。
35mm人文镜头，f/4光圈，侧顺光，冷调散射自然光线，光比1.5:1柔和层次。环境色温4800K清绿冷调，情绪关键词：世外花谷、悠然治愈、仙侠秘境、清新氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风电影胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非仙侠奇幻场景，现代/西式元素乱入，地貌/植被/人物造型错误。
```
