# 云梦浮空仙城

> 标签：国风仙侠/云梦仙境/浮空仙山 | 画幅：--ar 16:9 | 推荐模型：国风模型
```
独家秘法生成东方云梦仙境浮空仙山场景，主体是巨型青灰色悬空石岩构成的天然拱形长桥，穿透翻涌的白色棉花状云海，仙山边缘生长着粉紫柔色仙花植被，背景天空透出粉紫与鎏金色交织的梦幻霞光，整体青蓝梦幻色调，空灵治愈，充满修仙秘境的超脱氛围感。
24mm广角镜头，f/4光圈，大仰拍构图，侧逆光，冷调天空散射光线，光比1.8:1柔和层次。环境色温5000K清蓝粉紫调，情绪关键词：云梦仙境、空灵治愈、浮空仙域、修仙秘境氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风仙侠电影胶片质感，颗粒感适中，色彩通透梦幻。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非仙侠奇幻场景，现代/西式元素乱入，地貌/植被造型错误。
```
