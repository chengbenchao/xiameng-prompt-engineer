# 星环仙域飞升

> 标签：国风仙侠/星穹仙域/跨世界冒险 | 画幅：--ar 16:9 | 推荐模型：国风+科幻融合模型
```
独家秘法生成东方仙侠跨世界星环仙域场景，主体是两名背对镜头的修士立于白色积雪悬崖顶端：一人着银白战甲手持长剑，一人着素白长裙，二人仰望天空巨型透明鎏金光晕环形星门，星门旁漂浮细碎星尘与暗紫色晶石碎片，下方翻涌的云海中矗立半透明冰蓝色水晶仙城尖塔群，整体清蓝银白冷色调，空灵浩瀚，充满踏入异世界冒险的史诗级仙侠氛围感。
24mm广角镜头，f/4光圈，大仰拍构图，侧逆光，晴空冷调自然光线，光比1.8:1柔和层次。环境色温4800K清蓝冷调，情绪关键词：星环仙域、跨世界冒险、浩瀚空灵、史诗仙侠氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风仙侠电影胶片质感，颗粒感适中，色彩通透澄澈。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非仙侠奇幻场景，现代/西式元素乱入，星环/仙城/人物造型错误。
```
