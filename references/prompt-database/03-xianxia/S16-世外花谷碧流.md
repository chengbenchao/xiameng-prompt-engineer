# 世外花谷碧流

> 标签：国风仙侠/世外花谷/治愈秘境 | 画幅：--ar 16:9 | 推荐模型：国风+吉卜力融合模型
```
独家秘法生成东方仙侠世外花谷秘境场景，主体是身着素白长袍的仙人立于青灰色岩石悬崖顶端，俯瞰下方翡翠色澄澈峡谷碧流，两岸陡峭的青绿色巨型岩壁上和崖边铺满盛开的粉紫色球状繁花，清澈见底的碧色河水可见水下暗礁，整体清新治愈，充满世外仙境的悠然氛围感。
24mm广角镜头，f/4光圈，大俯拍构图，侧顺光，冷调散射自然光线，光比1.5:1柔和层次。环境色温4800K清绿冷调，情绪关键词：世外花谷、悠然治愈、仙侠秘境、清新氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风吉卜力融合风格电影胶片质感，颗粒感适中，色彩通透清新。
负面提示：低画质，模糊，变形，文字水印，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非仙侠奇幻场景，现代/西式元素乱入，地貌/植被/人物造型错误。
```
