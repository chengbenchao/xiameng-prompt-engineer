# 时空扭曲星象

> 标签：国风仙侠/天象奇观/时空扭曲/飞升穿越 | 画幅：--ar 16:9 | 推荐模型：国风+科幻融合模型
```
独家秘法生成东方仙侠时空扭曲天象奇观场景，主体是高空俯瞰视角下巨型流动卷曲的蓝白色棉絮状云团呈涡旋状向远方延伸，云层下方是青灰色连绵山脉与黄褐色开阔平原，上方是澄澈淡蓝色晴空，整体动感扭曲，充满时空折叠、仙人飞升穿越的震撼奇幻氛围感。
16mm鱼眼超广角镜头，f/4光圈，运动拖影动态特效，侧顺光，晴空冷调自然光线，光比1.5:1柔和层次。环境色温4800K清蓝冷调，情绪关键词：时空扭曲、天象奇观、飞升穿越、浩瀚震撼氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风仙侠电影胶片质感，颗粒感适中，色彩通透灵动。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非仙侠奇幻场景，现代/西式元素乱入，云团造型错误。
```
