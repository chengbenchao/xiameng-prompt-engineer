# 云海天瀑秘境

> 标签：国风仙侠/云瀑仙境/天际观瀑 | 画幅：--ar 16:9 | 推荐模型：国风模型
```
独家秘法生成东方仙侠云海天瀑场景，主体是两名身着素白长袍的修士与一只灵宠立于云海悬崖顶端，远眺天际巨型冰蓝色云瀑从高耸云层间倾泻而下，下方是漫无边际的棉花状白色云海，其间穿插绿松石色云间湖泊，背景是澄澈的钴蓝色晴空，整体清蓝通透色调，浩瀚空灵，充满俯瞰天地的仙人恢弘氛围感。
24mm广角镜头，f/4光圈，大俯拍构图，侧顺光，晴空冷调自然光线，光比1.8:1柔和层次。环境色温4800K清蓝冷调，情绪关键词：云海天瀑、浩瀚空灵、观瀑临仙、恢弘仙侠氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风仙侠电影胶片质感，颗粒感适中，色彩通透澄澈。
```
