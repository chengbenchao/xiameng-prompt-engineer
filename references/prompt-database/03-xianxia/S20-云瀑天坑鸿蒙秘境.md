# 云瀑天坑鸿蒙秘境

独家秘法生成东方仙侠鸿蒙天坑云瀑秘境场景，主体是两名修士立于黄褐色层状片岩悬崖顶端：一人着素白长袍，一人着玄色衣袍手持器物，二人俯瞰云海中巨型环形天坑，蔚蓝云瀑顺着天坑边缘倾泻而下，周围矗立尖黑色陡峭嶙峋仙山，天空散布白色棉絮状云海，小型黑色浮空仙舰零星穿梭其间，整体清蓝大气，磅礴震撼，充满鸿蒙初开、踏入太古秘境的宏大氛围感。
24mm广角镜头，f/4光圈，大俯拍大景别构图，侧顺光，晴朗天光自然光线，光比1.5:1柔和层次。环境色温4800K清蓝冷调，情绪关键词：云瀑天坑、鸿蒙秘境、磅礴震撼、宏大太古仙域氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风仙侠电影胶片质感，颗粒感适中，色彩通透澄澈。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非仙侠奇幻场景，现代/西式元素乱入，云瀑/人物/地貌/仙舰造型错误。
