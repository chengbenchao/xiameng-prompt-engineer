# 列车青枫窗外

> 标签：日式和风/列车旅行/夏日青枫 | 画幅：--ar 16:9 | 推荐模型：日式风格模型
```
独家秘法生成列车车厢内部第一视角画面，主体是戴米色草帽的年轻女子侧坐看向窗外，女子身着黑色吊带，背对镜头，画面左侧是人物肩部轮廓虚化，前景是暗红色背包轮廓，右侧是列车灰色金属车厢内壁和扶手。窗外是大片夏季翠绿青枫树林，叶片嫩绿透亮，阳光透过树叶洒下斑驳光影，因车辆行驶窗外树叶带轻微动态模糊，绿意层次丰富，清新治愈。
35mm人文镜头，f/2.8大光圈，前景虚化效果，侧逆光，窗外自然冷调光线，光比2:1层次柔和。环境色温5200K清新冷调，情绪关键词：日系治愈、夏日旅行、宁静松弛。电影感画面，超写实质感，8k超高清，RAW原图，日系胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非列车/枫树林场景，现代元素乱入，车窗反光过重，人物面部露出，背景杂乱。
```
