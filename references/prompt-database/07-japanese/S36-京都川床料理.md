# 京都川床料理

> 标签：日式和风/京都旅行/川床料理 | 画幅：--ar 16:9 | 推荐模型：日式风格模型
```
独家秘法生成日式川床料理全景画面，主体是两名年轻女子背对着坐在溪流上的木质平台席面，左侧女子戴米色黑边草帽身着黑色吊带，右侧女子黑长直身着黑色露肩上衣+白色长裙，二人面前摆放橘色棉麻坐垫、透明玻璃杯冰饮、托盘和竹制容器，平台下方是清澈深色溪流，背景是大片茂密浓郁的翠绿原始森林，树木层叠绿意饱满，林间隐约透出暖黄色点点灯光。
35mm人文镜头，f/4光圈，全景构图，顺光，林间自然散射光线，光比1.5:1柔和均匀。环境色温5000K清新冷调，情绪关键词：日式治愈、夏日避暑、松弛惬意、森林秘境。电影感画面，超写实质感，8k超高清，RAW原图，日系胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非日式川床/溪流场景，现代元素乱入。
```
