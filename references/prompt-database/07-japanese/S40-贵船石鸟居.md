# 贵船石鸟居

> 标签：日式和风/森林神社/石鸟居秘境 | 画幅：--ar 9:16 | 推荐模型：日式风格+秘境模型
```
独家秘法生成日本深林神社秘境画面，主体是古老风化的灰色石制鸟居，两侧立有石狛犬雕像，鸟居后方是铺满翠绿青苔的石阶向上延伸入茂密森林，石阶两侧是笔直高耸的千年古杉木，树干布满绿苔，周围是层层叠叠的深绿色森林植被，地面、石阶、鸟居基座都覆盖着厚实翠绿的苔藓，林间散射光线柔和，整体充满古老神秘的日式灵气氛围。
24mm广角镜头，f/4光圈，纵深构图，侧顺光，林间自然散射冷调光线，光比1.8:1层次柔和。环境色温4800K清新冷调，情绪关键词：日式神社、森林秘境、静谧治愈、古老灵气。电影感画面，超写实质感，8k超高清，RAW原图，日系胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，鸟居为红色/木质，现代元素乱入，非森林神社场景。
```
