# 泷神社长阶

```
独家秘法生成日本岐阜泷神社森林长阶画面，主体是笔直向上延伸的青苔覆盖青石板阶梯，中间有红褐色金属扶手，两侧是高耸入云的千年古杉木，树干布满厚实翠绿苔藓，周围是层层叠叠的深绿色蕨类和森林植被，地面、石阶边缘全部覆盖绒状翠绿苔藓，林间散射冷调光线柔和，整体充满静谧幽深、通往神域的日式灵气氛围。
24mm广角镜头，f/4光圈，纵深引导线构图，侧顺光，林间自然散射冷调光线，光比1.8:1层次柔和。环境色温4800K清蓝冷调，情绪关键词：日式神社、森林长阶、静谧神圣、幽深秘境。电影感画面，超写实质感，8k超高清，RAW原图，日系胶片质感，颗粒感适中，色彩通透自然。
```
