# 贵船神社石阶

> 标签：日式和风/神社石阶/森林秘境 | 画幅：--ar 9:16 | 推荐模型：日式风格+秘境模型
```
独家秘法生成日本深林神社石阶画面，主体是长满翠绿苔藓的青石板台阶向上延伸入茂密森林，石阶中间有旧褐色金属扶手，两侧是高耸入云的千年古杉木，树干布满厚实青苔，周围是层层叠叠的深绿色蕨类和森林植被，地面、石阶边缘都覆盖着绒状翠绿苔藓，林间散射冷调光线柔和，整体充满静谧幽深的日式神社灵气氛围。
24mm广角镜头，f/4光圈，纵深引导线构图，侧顺光，林间自然散射冷调光线，光比1.8:1层次柔和。环境色温4800K清新冷调，情绪关键词：日式神社、森林石阶、静谧幽深、灵气秘境。电影感画面，超写实质感，8k超高清，RAW原图，日系胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非森林石阶场景，现代元素乱入，石阶无苔藓，鸟居乱入。
```
