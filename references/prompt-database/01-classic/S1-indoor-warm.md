# 🏮 S1 · 室内暖调提示词库 (Indoor Warm)

> **环境色温**: 2700K | **面部色温**: 4800-5200K | **光位**: 侧逆光+暖金轮廓 | **氛围**: 暧昧拉扯

---

### 场景描述
古风中式室内环境，暖黄色烛光与纱幔营造暧昧拉扯氛围。背景有木质浴桶、古风木门、雕花窗棂等元素，光线柔和温暖，适合表现人物情感互动。

### 核心提示词模板
```
--ar 16:9
独家秘法生成古风室内暖调近景画面，机位正面偏侧 15-30 度。画面主体为古风人物上半身，背景为暖烛纱幔场景，人物位于画面中间或偏侧，神情微妙，光影暧昧。50-85mm 定焦镜头，F1.4 超大光圈，极致浅景深，背景古风室内场景极致虚化，焦内人物面部锐利清晰。侧逆光，光源位于人物侧方，暖金色烛光轮廓光，柔和暖调漫反射光线，整体暖黄色调，环境色温 2700K，人物面部色温 5200K，发丝金边，皮肤通透有质感。古风中式室内环境，朦胧烛火光影，暧昧拉扯的氛围感，电影感画面，超写实质感，8k 超高清，RAW 原图，人像摄影，极致细节，锐化清晰，高动态范围，光影层次丰富。

负面提示：低画质，模糊，变形，多余手指，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非古风室内场景，现代元素乱入，光线生硬刺眼。
```
