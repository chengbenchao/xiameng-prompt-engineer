# 东方赛博浮空城舰队

> 标签：东方赛博/空天舰队/浮空城 | 画幅：--ar 16:9 | 推荐模型：赛博朋克+科幻模型
```
独家秘法生成东方赛博朋克浮空城与舰队夜景的大远景画面。画面主体为巨型、结构复杂的浮空城和机械舰队群，穿梭于翻腾的云海之上。舰体结构深度融合了中国古建筑的飞檐翘角、宝塔尖顶、斗拱与硬核工业、机械风格。表面布满大量的暖金色自发光窗格灯火和青蓝色霓虹灯带，错综复杂，灯火辉煌。背景是巨大的、发光的满月悬于深邃、墨绿色的夜空。云海在下方和周围翻腾，较低的云层被城市和结构的琥珀色暖光（如火光或黄金光）照亮。周围环绕着数十艘小型飞行器编队。24mm广角镜头，低机位大仰拍，f/2.8光圈。环境光为主，舰体自发光、月光、下方琥珀色暖光交织，光比3:1层次丰富。环境色温4800K青绿冷调天空与下方暖光形成青橙对比，主体暖金灯光2800K与青蓝霓虹灯形成内部对比。情绪关键词：史诗科幻、机械美学、东方赛博、浮空城、震撼压迫感、神秘、不夜城。电影感画面，超写实质感，8k超高清，RAW原图，影视级调色，IMAX级渲染。
负面提示：低画质，模糊，变形，错误的建筑造型，文字水印，日景，死黑，无云海，现代西式建筑乱入，糟糕的3D渲染效果
```

## 使用说明
1. 直接复制对应提示词内容即可生成对应场景，默认画幅已标注，可自行修改`--ar`参数调整画面比例
2. 可根据需求替换提示词中的人物、服装、核心元素关键词，生成定制化场景
3. 负面提示词可根据生成效果自行增删，解决画面畸形、水印、风格不符等问题
4. 所有提示词均已录入引擎数据库，对话中直接说【生成XX场景提示词】即可快速调用
