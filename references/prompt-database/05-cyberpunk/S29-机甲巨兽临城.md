# 机甲巨兽临城

> 标签：国风赛博/机甲仙城/巨兽临城 | 画幅：--ar 16:9 | 推荐模型：国风+赛博朋克+机甲融合模型
```
独家秘法生成国风赛博机甲仙城巨兽临城场景，主体是身着鎏金暗纹战甲红裙的女侠背影立于高处，手持半透米白色油纸伞，背负长剑，仰望前方雨雾中悬浮的巨型黑金色机械仙兽/浮空仙舰，仙舰周身散落鎏金暖光星尘，左侧是挂满橙红灯笼的赛博古风木质长街，建筑融合古建飞檐与科技机械元素，雨夜中弥漫青绿色雾气，地面湿滑，整体青冷调与暖橙灯光对比强烈，充满赛博仙侠巨兽临城的震撼飒爽氛围感。
24mm广角低机位大仰拍镜头，f/2.8光圈，侧逆光，雨夜漫射暖冷对比光线，光比2:1层次丰富。环境色温4500K青橙对比调，情绪关键词：机甲仙城、巨兽临城、赛博仙侠、震撼飒爽氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风赛博电影胶片质感，颗粒感适中，色彩浓郁通透。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非国风赛博仙侠场景，现代/西式元素乱入，人物/机甲/建筑造型错误。
```
