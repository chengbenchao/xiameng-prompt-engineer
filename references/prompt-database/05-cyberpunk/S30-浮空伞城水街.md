# 浮空伞城水街

> 标签：国风赛博/浮空伞城/水街天街 | 画幅：--ar 16:9 | 推荐模型：国风+赛博朋克融合模型
```
独家秘法生成国风赛博浮空伞城水街天街场景，主体是雨夜青雾笼罩的赛博古风水城长街，中心河面倒映两侧暖橙灯光，两岸是层层叠叠依山势而建的飞檐古建楼宇，挂满橙红色灯笼，暖黄色窗灯鳞次栉比，天空中漂浮大量半透明红/黑油纸伞与飞鱼状赛博飞行载具，远处是高耸入云的鎏金发光通天浮城刺破青雾，整体青绿色调，暖橙灯光与冷青雾气交织，充满东方赛博不夜水城的梦幻迷离氛围感。
24mm广角对称纵深构图镜头，f/2.8光圈，侧顺光，雨夜漫射暖冷对比光线，光比1.5:1层次柔和。环境色温4500K青橙对比调，情绪关键词：浮空伞城、赛博水城、梦幻迷离、不夜天街氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风赛博电影胶片质感，颗粒感适中，色彩浓郁通透。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非国风赛博场景，现代/西式元素乱入，建筑/浮空伞/仙城造型错误。
```
