# 雨夜鬼市女侠

> 标签：国风赛博/雨夜鬼市/赛博江湖 | 画幅：--ar 16:9 | 推荐模型：国风+赛博朋克融合模型
```
独家秘法生成国风赛博朋克鬼市不夜城场景，主体是身着墨绿暗纹劲装的女侠背影立于湿漉漉的石阶上，背负暗绿油纸伞，腰佩长剑，手持短刃望向灯火通明的山城，周围是层层叠叠依山而建的国风古建融合赛博发光元素，挂满橙红色灯笼，建筑窗户透出暖金色灯光，雨夜中空气弥漫细小雨珠，地面湿滑倒映暖光，远处高耸赛博古风摩天塔流光溢彩，整体青蓝冷调与暖橙灯光对比强烈，充满赛博古风江湖的迷离氛围感。
24mm广角大仰拍低机位镜头，f/1.8大光圈前景实背景虚化，侧逆光，雨夜漫射暖冷对比光线，光比2:1层次丰富。环境色温4500K青橙对比调，情绪关键词：赛博鬼市、雨夜女侠、迷离江湖、国风赛博氛围感。电影感画面，超写实质感，8k超高清，RAW原图，复古港风赛博融合电影胶片质感，颗粒感适中，色彩浓郁通透。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非国风赛博场景，现代/西式元素乱入，人物/建筑造型错误。
```
