# 雨林不夜仙城

> 标签：国风赛博/雨林仙城/不夜天街 | 画幅：--ar 16:9 | 推荐模型：国风+赛博朋克融合模型
```
独家秘法生成国风赛博雨林仙城不夜天街场景，主体是雨夜雾气笼罩的国风古建长街，两侧是木质飞檐古建挂满橙红色灯笼与暖黄色窗灯，建筑上爬满翠绿色藤蔓与高大绿植，远处是多层高耸的鎏金飞檐仙楼，地面湿漉漉的青石板倒映暖橙灯光，零星行人撑伞漫步，整体青绿色雾气弥漫，暖冷光线交织，充满江南烟雨融合赛博仙城的迷离梦幻氛围感。
24mm广角镜头，f/2.8光圈，对称纵深构图，侧顺光，雨夜漫射暖冷对比光线，光比1.5:1层次柔和。环境色温4500K青橙对比调，情绪关键词：雨林仙城、不夜天街、烟雨迷离、国风赛博氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风赛博电影胶片质感，颗粒感适中，色彩浓郁通透。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非国风赛博场景，现代/西式元素乱入，建筑/植被造型错误。
```
