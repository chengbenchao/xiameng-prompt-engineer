# 月洞松影

> 标签：国风江南/月洞光影/诗意园林 | 画幅：--ar 16:9 | 推荐模型：国风+光影风格模型
```
独家秘法生成江南苏州园林月洞门光影画面，主体是米白色斑驳老墙挂着两幅深棕色木质圆形画心挂屏，天花板垂着中式四方木质宫灯搭配红色流苏，墙面左侧明式小几上放黄陶盆兰草，右侧是深棕色冰裂纹花格木窗，阳光透过窗格在墙面和挂屏上投下暖金色菱形细碎光影，整体古雅静谧，充满中式传统建筑的时光沉淀质感。
35mm人文镜头，f/2.8光圈，侧顺光，暖金柔和自然光线，光比2:1层次丰富。环境色温5200K暖金调，情绪关键词：月洞松影、中式雅致、静谧复古、东方古韵氛围感。电影感画面，超写实质感，8k超高清，RAW原图，国风电影胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非中式古建场景，现代/日式元素乱入，光线生硬刺眼。
```
