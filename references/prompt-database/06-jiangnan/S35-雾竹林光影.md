# 雾竹林光影

> 标签：国风禅意/雾竹林/光影意境 | 画幅：--ar 16:9 | 推荐模型：国风+禅意风格模型
```
独家秘法生成中式园林清晨雾中竹林景致画面，主体是挺拔修长的翠绿青竹，竹干被暖金色晨光勾勒出柔和轮廓光晕，背景是朦胧暖金色雾气，竹林影子在雾气背景上形成层次丰富的层叠竹影，整体光影层次丰富，静谧雅致，充满东方禅意的诗意氛围。
50mm标准镜头，f/2.8光圈，侧逆光，丁达尔柔和光线穿透雾气，光比2:1层次柔和。环境色温5200K暖金调，情绪关键词：晨雾竹林、中式禅意、静谧雅致、东方美学。电影感画面，超写实质感，8k超高清，RAW原图，国风胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非中式竹林场景，现代元素乱入，光线生硬刺眼，无雾气/竹影层次。
```
