# 苏州园林烟雨

> 标签：国风江南/烟雨园林/治愈意境 | 画幅：--ar 16:9 | 推荐模型：国风+江南风格模型
```
独家秘法生成江南苏州园林雨天全景画面，主体是古朴厚重的石制平桥架在平静碧绿水面上，桥边是斑驳岁月痕迹的徽派白墙黛瓦建筑，墙面有自然的水渍晕染痕迹，岸边巨大香樟树树叶翠绿茂密，垂落的枝条遮挡部分墙面，水面漂浮着零星嫩绿荷叶，远处水面升腾着薄薄的白色水雾，天空是阴天灰蓝色调，整体烟雨濛濛，绿意清新，充满中式江南水乡的静谧诗意。
35mm人文镜头，f/4光圈，雨天自然散射光线，光比1:1柔和均匀。环境色温4800K清新冷调，情绪关键词：江南烟雨、园林静谧、中式治愈、素雅诗意。电影感画面，超写实质感，8k超高清，RAW原图，国风胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非江南园林场景，现代建筑乱入，水面无雾气/荷叶，晴天强光影，建筑为日式风格。
```
