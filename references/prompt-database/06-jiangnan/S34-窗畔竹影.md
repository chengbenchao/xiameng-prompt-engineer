# 窗畔竹影

> 标签：国风禅意/窗畔竹影/东方美学 | 画幅：--ar 16:9 | 推荐模型：国风+禅意风格模型
```
独家秘法生成中式传统园林窗景画面，主体是深黑色竖向木质花格窗形成天然画框，窗外是暖调光线照射下的松竹景致：左侧是遒劲苍松的深绿色枝桠，右侧是挺拔修长的翠竹，竹干被暖金色阳光勾勒出柔和光晕，背景是朦胧淡金色雾气天空，整体光线柔和静谧，充满东方禅意美学的雅致氛围感。
50mm标准镜头，f/2.8光圈，侧逆光，丁达尔柔和光线，光比2:1层次柔和。环境色温5000K暖金调，情绪关键词：中式禅意、窗畔观竹、静谧雅致、东方美学。电影感画面，超写实质感，8k超高清，RAW原图，国风胶片质感，颗粒感适中，色彩通透自然。
负面提示：低画质，模糊，变形，文字水印，动漫风，卡通风，3D渲染劣质效果，色彩失真，过曝，死黑，非中式窗棂/松竹场景，现代/日式元素乱入，光线生硬刺眼。
```
