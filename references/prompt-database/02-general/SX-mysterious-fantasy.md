# 🌌 SX 3D CG 神秘玄幻

**适用场景**：所有场景分镜、角色场景图、氛围图
**默认风格**：所有图片统一使用此风格，除非用户明确指定其他场景
**版本**：v1.0（2026-04-23）

## 核心参数

| 维度 | 参数 |
|------|------|
| **环境色温** | **5800K** |
| **面部色温** | **5500K** |
| **标准光位** | 侧逆光 / 伦勃朗光 + 体积雾 |
| **焦段** | 按景别匹配（24-135mm） |
| **画幅** | `--ar 9:16`（竖屏人物） / `--ar 16:9`（横屏场景） |
