## 🚀 快速开始

### 1. 安装
```bash
cp -r xiameng-prompt-engineer /path/to/your/agent/workspace/skills/
```

### 2. 触发方式
在对话中描述你的画面需求，例如：
> "帮我写一个 22 岁东方女性，穿 C01，在 S3 宗门场景的提示词。"

### 3. 模式切换
| 模式 | 触发方式 | 输出内容 |
|:---|:---|:---|
| **快速模式** | 默认 | 结构化专业提示词 + 核心参数 |
| **自然模式** | 指令含"自然模式" | 大白话自然语言风格提示词 |
| **标准模式** | 指令含"分析" | 完整导演思维推导 + 评分报告 |

## ⚙️ 技术架构

本 Skill 由以下核心组件构成：

```
xiameng-prompt-engineer/
├── SKILL.md                      # 5 步工作流 (SOP) + 红线自检逻辑
├── README.md                     # 本文档
├── references/
│   ├── core-rules.md             # 硬性约束参数（色温表/焦段表）
│   ├── costume-library.md        # 服装库总索引
│   ├── 服装参数库/               # 12 套服装独立参数文档
│   ├── prompt-database/          # 场景提示词库（按系列分文件夹）
│   │   ├── 01-classic/           # S1-S8 经典古风
│   │   ├── 02-general/           # S9-S11, SX 通用标杆
│   │   ├── 03-xianxia/           # S12-S20 仙侠奇幻
│   │   ├── 04-wuxia/             # S21-S26 武侠江湖
│   │   ├── 05-cyberpunk/         # S27-S30 赛博古风
│   │   ├── 06-jiangnan/          # S31-S35 江南园林
│   │   ├── 07-japanese/          # S36-S41 日式和风
│   │   ├── 08-scifi/             # S42 科幻史诗
│   │   └── COSTUME_MATCH_GUIDE.md # 42×12 完整搭配矩阵
│   └── awesome-gpt-image-2-prompts/ # GPT-Image-2 标杆案例库
```

## ⚠️ 使用须知

1. **模型要求**：建议使用 **GPT-4o**、**Claude 3.5 Sonnet** 或 **Qwen-Max** 等逻辑能力强的模型。
2. **参考图一致性**：提示词中的"参考图一"等占位符，需配合垫图（Image Prompt）或 ControlNet 使用。
3. **参数微调**：`core-rules.md` 参数可编辑，替换为你自己的项目标准。
