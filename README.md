## 🚀 快速开始

### 1. 安装
```bash
cp -r xiameng-prompt-engineer /path/to/your/agent/workspace/skills/
```

### 2. 触发方式
在对话中描述你的画面需求，例如：
> "帮我写一个 22 岁东方女性，穿 C01，在 S3 宗门场景的提示词。"

### 3. 模式切换
| 模式 | 触发方式 | 输出内容 |
|:---|:---|:---|
| **快速模式** | 默认 | 11 维分段专业提示词 + 紧凑参数 |
| **自然模式** | 指令含"自然模式" | 大白话自然语言风格提示词 + 6 维关键参数 |
| **标准模式** | 指令含"分析" | 完整导演思维推导 + 11 维参数表 + 质检报告 |
| **运动模式** | 指令含"运动/视频"或发视频 | 运动提示词 + 三模块 + 英文 --motion 参数 |

## 📐 输出格式规范

### 快速模式输出（默认，v5.0 11维分段格式）
```
【画面类型】独家秘法生成[风格][场景][景别]画面。
【主体】画面主体为...（含服装细节 + 头身比 + 材质纹理）
【环境】[地点 + 空间层次 + 背景元素 + 景深 + 前景]
【光影】[主光源 + 辅助光源 + 光位 + 光比 + 体积光]
【色温】[环境色温K + 主体色温K + 对比关系]
【材质】[至少2种材质描述]
【镜头】[焦段] 镜头,[光圈],[机位],[方向],[构图]
【运动】固定镜头，无运动元素（或运动描述）
【氛围】[情绪状态 + 空间纵深]（只写状态，不写动作）
【风格质感】电影感画面，超写实质感，8K超高清，RAW原图，影视级调色，IMAX级渲染
【负面提示】[场景化负面词]
```

### 自然模式输出（描述性语言，减少技术参数堆砌）
```
[完整提示词（自然语言风格，色温→暖调/冷调，光比→柔和/戏剧性，焦段→广角/长焦）]

📋 关键参数(6 维)
🎬 景别:xxx | 📐 高度:xxx | 🧭 方向:xxx | 🔍 焦段:xxx | 💡 光影:xxx | ✨ 氛围:xxx
```

### 标准模式输出（含完整质检报告）
```
## 📋 参数拆解表（11 维度）
| D1 画面类型 | D2 主体 | D3 环境 | D4 光影 | D5 色温 |
| D6 材质 | D7 镜头 | D8 运动 | D9 氛围 | D10 风格质感 | D11 负面提示 |

## ✅ 质检报告
完整性:XX/30 | 准确性:XX/40 | 表现力:XX/30
总分:XX/100 → [优秀/通过/调整/重写]

## 📝 完整提示词
[11 维分段提示词正文]
```

### 运动模式输出（视频生成专用）
```
[11 维分段运动提示词正文，D8 填写完整运动参数]

【运动控制】整体节奏 + 元素运动描述
【镜头控制】镜头运动类型 + 速度 + 稳定度
【空间层级】前景—中景—背景层次

--motion [英文运动参数]
--no [英文负面参数]
```

## ⚠️ 使用须知

1. **模型要求**：建议使用 **GPT-4o**、**Claude 3.5/4 Sonnet**、**DeepSeek-V3** 或 **Qwen-Max** 等逻辑能力强的模型。
2. **参考图一致性**：提示词中的"参考图一"等占位符，需配合垫图（Image Prompt）或 ControlNet 使用。
3. **参数微调**：`core-rules.md` 参数可编辑，替换为你自己的项目标准。
